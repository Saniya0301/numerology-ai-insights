## 🌿 Overview

**Numerology AI Insights** is a full-stack AI application designed to transform
numerological calculations into a structured, personalized digital experience.

The platform accepts a user's **full name and date of birth**, calculates multiple
numerological indicators, retrieves relevant knowledge from a curated knowledge base,
and uses AI to generate contextual interpretations.

Rather than presenting isolated numbers, the application connects those numbers to
different areas of life including:

- Career & professional direction
- Money & financial tendencies
- Love & relationships
- Personality & behavioral patterns
- Strengths & challenges
- Personal growth
- Yearly themes
- Compatibility
- Karmic influences
- Pinnacle cycles

The platform also provides a conversational space where users can ask
questions about their individual profile and generate a detailed,
long-form PDF report.

🔢 Advanced Numerological Calculations

The platform goes beyond basic Life Path calculations.

Karmic Lessons

Identifies numerical patterns associated with missing or underrepresented
energies in the name-based calculation.

Pinnacle Cycles

Calculates the four major pinnacle cycles and presents their corresponding
numbers and life-stage interpretations.

Challenge Numbers

Calculates challenge numbers to identify recurring developmental themes.

Maturity Number

Calculates the maturity number to provide an additional long-term
perspective on personal development.

Life Path Breakdown

Instead of only displaying the final number, the application can show
the calculation path used to arrive at the Life Path result.

🧠 AI Numerology Q&A

The application includes an interactive questioning layer.

Users can ask questions about their own numerological profile instead of
only reading a predefined interpretation.

Example questions:

What type of career environment suits me?

Why do I repeatedly face the same relationship patterns?

What does my Personal Year indicate?

What are my strongest professional qualities?

The AI uses the user's calculated profile together with the application's
numerology knowledge base to produce contextual answers.

💕 Compatibility Analysis

The Compatibility module allows users to analyze two individuals together.

Users can provide the relevant information for two people and receive
an AI-assisted compatibility interpretation.

The analysis can explore areas such as:

Personality dynamics
Relationship tendencies
Strengths
Potential friction points
Communication
Emotional compatibility
Long-term dynamics

The goal is not simply to produce a compatibility score,
but to provide a structured interpretation of the numerical relationship.

⚙️ Local Installation
1. Clone the repository
git clone https://github.com/Saniya0301/numerology-ai-insights.git
cd numerology-ai-insights
2. Create a virtual environment
Windows
python -m venv .venv

Activate it:

.venv\Scripts\activate
macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
3. Install dependencies
pip install -r requirements.txt
🔐 Environment Variables

Create a .env file according to the variables expected by the backend.

Example:

GOOGLE_API_KEY=your_api_key_here

Never commit your .env file.

The repository includes a .gitignore to prevent secrets and local
environment files from being tracked.

▶️ Run the Backend

From the project root:

cd backend
uvicorn api:app --reload --port 8000

The API will be available at:

http://localhost:8000
🌐 Run the Frontend

From the project root:

cd frontend
python -m http.server 5500

Then open:

http://localhost:5500

The frontend communicates with the FastAPI backend through the API
base URL configured in:

frontend/script.js
🔌 API Layer

The FastAPI backend exposes endpoints for the major application features,
including profile generation, AI-powered analysis, compatibility,
question answering, and report generation.

The backend is designed as a service layer between the browser-based
frontend and the numerology / AI systems.


----
🔒 Security Considerations

API keys are intentionally kept outside the frontend.

Sensitive credentials should be supplied through environment variables
during local development and deployment.

Never place private API keys directly inside:

frontend/script.js

or any other browser-accessible file.
